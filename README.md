# Generation Vault

A Stacks blockchain smart contract for multi-generational STX inheritance and estate planning with time-locked beneficiary withdrawals.

## Overview

**Generation Vault** enables grantors to create decentralized, immutable trusts where beneficiaries can withdraw their allocated STX tokens only after specified block heights are reached. Perfect for long-term wealth transfer, estate planning, and family wealth management across generations.

## Features

- ✅ **Multi-Beneficiary Support** – Register multiple beneficiaries with custom percentage shares
- ✅ **Time-Locked Withdrawals** – Funds unlock at specified block heights
- ✅ **Grantor Control** – Only the grantor can add beneficiaries and lock the trust
- ✅ **Immutable State** – Once locked, trust configuration cannot be modified
- ✅ **Single Withdrawal** – Each beneficiary can only withdraw once
- ✅ **Event Emission** – Full transaction history via event logging
- ✅ **Access Control** – Comprehensive validation for all operations
